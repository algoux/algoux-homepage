# algoUX Home Page

<https://algoux.org>

## Started

```bash
pnpm i
```

---

## Develop

```bash
pnpm run dev
```

---

## Build

```bash
pnpm run build
```

Set `GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX` or `VITE_GOOGLE_ANALYTICS_ID=G-XXXXXXXXXX` to enable Google Analytics during dev/build.

Set `BEIAN=备案号` to display the ICP filing number above the final footer line.
